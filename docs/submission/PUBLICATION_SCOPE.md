# 최종 공개 범위

포트폴리오에서 기획 의도와 구현 결과를 확인할 수 있도록 코드·문서·텍스트 검증 기록을 보관합니다. 사용자와 정한 최종 범위에 따라 이미지·PDF와 고객별 재구매 원자료 한 파일은 제외했습니다. API 키와 개인 기록 설정도 포함하지 않습니다.

## 포함

- 앱 서버·화면·업무 계산·상태 전환·GPT 연결 코드, 실행·배포 설정.
- 설계 설명 7개 문항, 기능 설명, 원본 대조와 변경 이력, 테스트·검증 도구, 텍스트 실행 결과.
- 대회 제공 문제 설명·BPMN·가상기업 자료 중 공개 제외 파일을 뺀 자료, 실행용 추출 JSON.
- 재구매 파일의 역할·구조·제외 이유를 설명하는 개요.

## 제외

- 모든 래스터·벡터 이미지와 PDF. 문서의 해당 링크는 공개본에서 제외 안내로 바꿉니다. 원본 텍스트에 남은 경로명은 출처 설명이며 파일 제공을 뜻하지 않습니다.
- `01_참가자_배포용/04_원본데이터/02_masil/marketing/mkt_repurchase_ms.csv`. 현재 앱과 실행 스크립트는 이 파일을 사용하지 않습니다.
- `.agents/`, `.codex/`, `.claude/`, `.axhub/`, API 키·DB 접속정보·세션 비밀값·로컬 DB.

앱 코드는 실제 구현 범위를 보여줍니다. 공개 저장소가 곧 실행 중인 서비스나 실회사 연동을 뜻하지 않습니다. 일부 원본 안내 HTML에서 참조하는 설명 이미지는 공개하지 않으며, 데이터·승인·계산의 구현 코드와 텍스트 설명은 보존합니다. 과거 검증 결과를 이번 업로드에서 새로 재실행한 결과로 해석하지 않습니다.

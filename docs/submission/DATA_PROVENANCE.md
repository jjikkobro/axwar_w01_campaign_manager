# 공개 자료의 출처와 성격

이 저장소의 `01_참가자_배포용/`는 AX 인재전쟁 대회에서 제공한 문제·가상기업 시나리오·데이터입니다. 참가자가 수집한 실제 고객·회사 운영 자료와 구분합니다.

## 원본 안내의 근거

- `01_참가자_배포용/A01.html`: “가상기업 기준일은 2026년 7월 1일”이라고 명시합니다.
- `01_참가자_배포용/A02.html`: Aurora Holdings, Corevia Cosmetics, Masil Commerce, Celtonic Labs를 과제의 기업 시나리오로 소개합니다.
- `data/`의 실행용 추출값과 참고 계산에는 이 제공 자료의 파일명·출처·가정이 연결돼 있습니다.

## 공개에서 제외한 고객별 재구매 참고 파일

`01_참가자_배포용/04_원본데이터/02_masil/marketing/mkt_repurchase_ms.csv`는 같은 가상기업 과제 패키지에 포함된 참고 자료입니다. 사용자가 이 파일만 공개에서 제외하도록 선택했으며, 이 저장소에는 원본 행을 올리지 않고 이 개요만 남깁니다. 구분자는 `|`이며 고객 참조 ID, 최초 주문일, 재주문일, 기간 내 재구매 여부의 네 열로 구성됩니다. 원본의 행 수는 13,105개입니다.

열 이름은 `customer_ref`, `first_order_date`, `reorder_date`, `reorder_within_90d`입니다. 이름·전화번호·이메일·주소·계좌번호 열은 없으며, 텍스트 검사에서도 이메일과 국내 휴대전화번호 형식은 발견되지 않았습니다. 고객 참조 ID는 영문·숫자·구분자 형태입니다. 이 설명은 파일 구조와 과제 출처를 밝히는 것이며 실제 고객 자료의 익명화 검증을 수행했다는 뜻이 아닙니다.

현재 앱의 `app/`·`scripts/`에는 이 파일을 읽는 코드가 없습니다. 원본 과제 패키지와 구현에 실제 사용한 범위를 구분해 보관합니다.

## 공개에서 제외한 것

API 키, DB 접속정보, 세션 비밀값, 개인 기록 키와 도구 설정, 로컬 DB·런타임 상태는 포함하지 않습니다. 검증 이력은 당시 실행의 기록이며 실제 은행·공급처 업무가 수행됐다는 증거가 아닙니다.

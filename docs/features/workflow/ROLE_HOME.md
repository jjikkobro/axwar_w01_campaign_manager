## 담당자 첫 화면

업무 콘텐츠를 다음 두 섹션으로 제한합니다. 마케팅 역할에만 **새 캠페인 생성** 버튼을 표시합니다.

1. **내가 처리할 캠페인**: 내 역할의 미완료 캠페인 작업이 있거나 현재 단계의 담당 역할인 캠페인. 한 캠페인은 한 카드로 묶습니다. 기한·처리할 일·현재 상태·7단계 위치와 처리 버튼을 표시합니다.
2. **처리한 캠페인의 현재 위치**: 내 역할이 명시적으로 처리한 기록이 있고 현재 내 미완료 작업이 없는 캠페인. 현재 담당 부서·단계·종료 여부를 표시합니다. 앞 목록과 중복하지 않습니다.

‘처리한 캠페인’은 캠페인 전체 완료라는 뜻이 아닙니다. 다음 부서 검토 중인 건도 포함합니다. 종료 후 실제 성과 확인처럼 남은 캠페인 작업이 있으면 첫 목록에 남습니다. 자동 단계 전이·재판정·단순 열람을 사람이 처리한 이력으로 계산하지 않습니다. 담당 부서의 직접 입력·검토·회신·승인 사건을 근거로 분류합니다. 기한이 있는 실제 후속 작업은 그 기한을 사용합니다.

현재 역할 선택은 기존 프로토타입의 부서별 시연 방식입니다. 개인별 계정·담당자 배정 인증을 새로 구현한 것은 아닙니다. 브라우저 저장 대신 URL의 역할과 서버 DB 기록을 사용합니다.

캠페인 카드에서 상세 처리 화면 또는 해당 수요/협의 작업으로 이동합니다. **현재 위치 보기**는 담당 역할의 대기·감시 화면으로 이동합니다. 상세 화면의 원본 단계 플로우와 사람의 처리 방식은 유지합니다. 이전 `/#screen=...` 주소와 시안 비교 주소는 `/campaign`으로 연결하므로 기존 링크를 보존합니다. 기안 없는 `/hub`의 내 할 일도 새 첫 화면으로 연결합니다.

## 시스템 관리자

별도 `/admin` 페이지를 다음과 같이 구분합니다.

- **기준 자료**: 자료별 담당 부서·행 수·버전·출처, 현금 계산 설정 상태, 세부 자료 관리 연결.
- **별도 업무**: 캠페인 목록에서 제외한 연체 회수/지급 확인, 별도 연간계약 대상·전속계약 통보 작업. 원본 기록을 조회하며 열람으로 승인·통보·완료하지 않습니다.
- **시스템 기록**: 전사 공통 사건을 포함한 최근 기록.

세부 관리 화면 `/operations`도 관리자 명칭과 관리자 홈/담당자 홈 연결로 표시합니다. 캠페인 상세의 추가 메뉴에서 자료 관리 대신 시스템 관리자 페이지로 연결합니다. 일반 캠페인 작업 화면의 목록에는 해당 캠페인의 담당 작업만 표시합니다.

이전 ‘별도 업무 미표시’ 규칙은 **담당자 캠페인 화면에 적용**하고, 관리자에서는 명시적으로 분리해 조회합니다. 내부 데이터·현금 계산·승인권한·기존 작업은 변경하지 않습니다. 관리자 페이지 구분은 실제 계정별 접근 권한 통제가 아니며 기존 공유 접속 인증을 사용합니다. 별도 업무에 대해 새로운 관리자 승인 권한을 부여하지 않습니다.

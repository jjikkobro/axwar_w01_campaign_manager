# 업무 검토 화면의 정보 구조

## 공통 표시 원칙

- 판단: 작성자·담당자 판단·시스템 계산을 구분합니다.
- 수치: SKU별 확인 공급 기준과 보충 가정 반영 결과를 표로 비교합니다.
- 행동: 담당자가 확인할 내용·발주 검토일·리드타임을 제품별 카드로 정리합니다.
- 근거: 원문·출처·긴 설명은 상세 보기에서 확인합니다. 저장된 원문은 수정하지 않습니다.
- GPT: 요약·위험·대안·확인 질문·근거를 구분해 표시합니다. 담당자 의견 반영은 원문을 사용하며 표시를 바꿨다고 결재·업무 상태를 변경하지 않습니다.

수량은 천 단위 쉼표와 소수 최대 2자리로 표시합니다. 원본 정밀도와 계산식은 그대로입니다. 수정 가능한 입력란은 유지하고, 읽기 전용과 모바일의 원문 펼치기·표 가로 스크롤을 지원합니다.

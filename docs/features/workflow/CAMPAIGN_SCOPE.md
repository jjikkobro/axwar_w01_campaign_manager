# 캠페인 운영 중심 표시 범위 · 2026-11-10

사용자 지시: 캠페인 운영 이외의 검토 데이터는 솔루션에 표시하지 않는다. 연체 회수·인플루언서 계약 등은 검토에서 우선 제외하고 필요한 내부 계산은 유지한다.

후속 사용자 요청에 따라 별도 업무는 **담당자 화면에서 제외하되 시스템 관리자 페이지에서 분리해 조회**합니다. 현재 첫 화면과 관리자 기준은 [ROLE_HOME.md](ROLE_HOME.md)를 확인합니다.

## 적용

- 역할별 화면·내 할 일·결재 목록·부서 협의/후속 의무·사건 이력·세부 관리에서 연체 회수 확인, 전속계약 검토/갱신/통보, 연간계약 결재 대상을 표시하지 않습니다.
- 캠페인 기안·수요·재고/입고·관련 발주·현금 영향·해당 결재·공급 회신·일정 정리·성과 확인은 유지합니다.
- 인플루언서를 활용한 **캠페인 매체 선택과 성과 정보**는 유지합니다. 제외 대상은 별도의 전속계약 업무입니다. 캠페인 결재에 따른 그룹 보고도 유지합니다.
- AR/AP·계약 원본·기존 확인 작업·이력은 서버에 보존합니다. 내부 현금 계산·승인 규정은 변경하지 않습니다. 시나리오 가정 선택과 현금 결과는 캠페인의 현금 제약을 검토하는 용도로 유지합니다.
- 화면에서 제외한 기존 연간계약 대상은 캠페인 재무 자료를 저장할 때 원래 값 그대로 보존합니다. 숨김을 삭제·승인·완료 처리로 해석하지 않습니다. 캠페인 종료/철회 입력으로 별도 전속계약 통보를 자동 기록하지 않습니다.

`web/campaign-scope.js`가 표시용 응답 사본과 원본 시안의 별도 업무 카드·검토 체크를 제한합니다. 서버 API의 원본과 DB는 유지합니다. 접근 통제나 데이터 삭제 기능은 아닙니다. 원본 `W01_screens`와 보호 설정은 변경하지 않았습니다. 이번 표시 범위 조정은 이전의 원본 픽셀 일치 기준보다 우선하는 사용자 수정 지시이며, 기본 화면의 나머지 배치·캠페인 단계는 유지합니다.

# SCM 대조 화면: 신청 예상안 보존과 구체적인 공급 추천

## 달라 보이던 이유

이전 화면은 캠페인 시작 전부터 종료일까지 최초 음수 재고를 하나의 캠페인 문제로 표시했습니다. 마케팅의 예상 발주 수량/입고 가정과 확인 공급만 반영하는 SCM 검산도 구분하지 않았습니다. 또한 SCM 발주안 입력은 마케팅이 채택한 예상안을 재사용하지 않고 자체 기본값을 만들 수 있었습니다.

## 화면과 인계

발주안 편집 섹션을 제거했습니다. 원본 시안은 보존하고 마이그레이션 출력과 재생성 함수에 반영했습니다. SCM은 마케팅이 채택한 예상 수량·단가 또는 현재 기안과 일치하는 SCM 검토 자료를 바탕으로 판단·인계합니다. 이 값들은 실제 발주 승인이나 공급 회신이 아닙니다. 신규 수량 변경이 필요하면 마케팅 예상안을 수정·재검토하는 기존 흐름을 사용합니다.

대조 상단은 확인 공급 기준의 품절과 신청 예상안의 입고 가정을 구분합니다. 추천과 다른 판단의 사유만 필수이며, 현재 추천과 맞는 판단의 사유는 선택 사항을 유지합니다. 추천한 대안은 인계 모달에 자동으로 들어갑니다.

## 추천 기준

- **캠페인 기간 공급 가능:** 현재고·확인 공급·다른 승인 캠페인 수요를 반영한 캠페인 기간 최소 재고가 음수가 아닙니다. 캠페인 시작 전의 부족은 별도로 경고하되 캠페인 수요의 문제로 묶지 않습니다.
- **신청 예상안 공급 가능 · 입고 조건 확인:** 확정 공급만으로는 부족하지만 신청한 수량이 가정 판매가능일에 입고되면 전 기간 공급이 충분한 경우입니다. 이 가정은 복사한 시나리오 원장에서만 계산하며 실제 공급·확인 재고에 넣지 않습니다. SCM은 수량·판매가능일을 확인해야 합니다.
- **조정 필요:** 실제 부족일·최저 재고·이번 캠페인을 제외했을 때의 재고를 제시합니다. 확인된 공급 회신의 입고일 후보로 시작/종료일을 함께 이동하고 전체 SKU 기간을 재검산합니다. 충분하지 않으면 그 날짜를 해결안으로 추천하지 않습니다.
- **수요 대안:** 기본 판매와 기존 약속만으로 충분한 경우 해당 SKU의 추가 수요 상한을 이분 탐색으로 검산합니다. 기본 판매만으로도 부족하면 캠페인 축소만으로 해결된다고 말하지 않습니다.
- **입고 대안:** 첫 부족일 이전에 추가 판매가능 입고가 한 번에 반영되고 다른 수요·공급이 유지된다는 조건에서 최소 추가량을 계산합니다. 실제 공급 가능량이나 납기를 보장하지 않습니다.

각 추천은 원본 현재고/주간 판매, 확인 회신의 PO ID·판매가능일·수량, 명시된 입력 수요와 모델 가정을 근거로 합니다. 확인되지 않은 기존 PO 날짜를 확정 입고로 취급하지 않습니다. 공장 가용 능력이나 납기를 새로 지어내지 않습니다. 생성형 AI를 호출한 답변이 아닌 규칙·시나리오 검산 기반 추천입니다.

## 검증

단위 테스트 174건. 확인된 8/6 입고로 캠페인을 8/6~8/12에 옮긴 경우, 기간 최소 1,551EA가 남는 격리 DB 사례를 실제 화면에서 확인했습니다. 이는 모의 회신이 있는 해당 검증 사례의 값이며 모든 캠페인의 추천 날짜가 아닙니다.

캠페인 전 부족/기간 내 정상, 신청 입고 가정에만 의존하는 조건부 정상, 불충분한 입고의 날짜 변경 거절, 확정되지 않은 입고의 해결안 거절, 수요 축소로도 불가능한 사례, 정량 수요 상한을 확인했습니다. 발주안 편집이 없어도 마케팅 예상 12,000EA·16,800원 단가가 재무 인계에 보존되는지 DB로 검증했습니다.

# 마케팅 예상안 신청과 승인 후 SCM 일정 조회

## 적용된 업무 경계

마케팅 신청에는 캠페인 내용·희망 집행 기간·SKU 수요·예상 발주량·예상 단가/조달비·캠페인 집행 예산을 담습니다. 상품 조달 예상비용과 표본 캠페인 집행 예산은 계속 구분합니다. 실제 발주·지급·입고 일정을 마케팅에게 입력시키지 않습니다.

요청에 따라 상단 네 단계 작성 가이드를 제거했습니다. 입력란의 필요한 값 표시·금액 천 단위 쉼표·계산 결과 스크롤은 유지했습니다. 마케팅의 정산일/계약 확정기한·발주 지급일 입력, 일정 역산·정산 조건 카드와 현금/결재선 결과는 제거했습니다. 마케팅 신청 결과는 예상 발주량·예상 조달비 두 항목으로 정리합니다.

## 신청과 부서 검토

신규 화면은 `submission_mode=estimate_only`로 신청합니다. 캠페인 정산일과 계약 확정기한은 신청의 필수값이 아니며 시스템에서도 실제 값으로 보관하지 않습니다. 예상안 입력의 지급일도 비웁니다. 수요·예상량·단가를 검토한 SCM은 일정이 없더라도 재무에 검토 자료를 넘길 수 있습니다.

재무 승인 검토에는 계획 유출일과 30억 기준 판정이 필요하다는 기존 규칙을 유지합니다. 계획 날짜는 SCM·재무 담당자가 확인하여 재무 검토에 기록합니다. 마케팅에게 다시 입력을 요구하거나 미확정 날짜를 시스템이 창작하지 않습니다. 계획 날짜 없이 최종 승인·발주로 통과하는 기능은 없습니다. 날짜를 요구하는 기존 API 모드도 그대로 유지합니다.

승인은 기존 승인권자가 명시적으로 기록하고, SCM은 승인 범위 내에서 발주합니다. 실제 지급일/수량이 승인 범위와 다르거나 공급 회신이 변경되면 기존 재판정·재승인 규칙이 적용됩니다.

## 승인 후 마케팅이 보는 일정

마케팅 대기·일정 정리 화면에 `SCM 발주·입고 일정`을 표시합니다.

| 시점 | 표시 |
|---|---|
| 신청·검토·승인만 기록 | 실제 발주 일정 없음. SCM 기록 대기 |
| SCM 발주 기록 | 발주일·수량·발주서 지급예정일. 입고일은 공급처 회신 대기 |
| 유효한 공급 회신 등록 | 확인된 SKU별 입고예정일/분할 수량·지급예정일 표시 |
| 수량/지급일 변경 회신 | 변경 회신 재확인 중. 미승인 변경을 확정 일정으로 표시하지 않음 |

기존 PO에 대해 SCM이 남긴 유효한 입고 확인도 표시합니다. 신청자가 입력했던 가정 날짜로 채우지 않습니다. 내부 저장은 마케팅 신청 원본을 덮어쓰지 않고 SCM 발주/회신을 참조하는 조회 모델로 연결합니다. 기존 일정표·제품별 입고 설명도 이 자료를 사용합니다.

마케팅 대기·정리 화면은 10초 간격으로 가벼운 버전 조회를 수행하고, SCM 등의 새 기록이 있으면 자동으로 다시 읽습니다. 숨겨진 탭 또는 작성 중인 화면은 자동 갱신하지 않습니다. 작업 중인 입력을 덮어쓰지 않습니다. 다른 화면으로 이동하면 조회를 중단합니다.

여기서 표시하는 일정은 **입고·지급 예정**입니다. 은행 지급이나 실제 창고 입고를 자동 완료하지 않습니다. 실제 공급처/ERP 연결 없이 모의 입력으로 시연했으며 해당 출처를 표시합니다. 기존 통합 재고·현금 계산은 기록된 신규 발주와 확인 회신을 기존 정책대로 반영합니다.

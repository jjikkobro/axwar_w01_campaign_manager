# 마케팅 작성 안내·금액 표시·계산 결과 이동

기존 기안 프레임과 입력·승인 규칙을 유지하며 처음 사용하는 담당자를 위한 안내를 보완했습니다.

- 상단 작성 안내는 캠페인 정보 → 제품·수요 → 발주·예산·일정 → 계산 결과·상신의 네 단계와 현재 미입력 항목을 표시합니다. 항목 버튼과 `다음 입력으로`를 누르면 해당 필드로 이동하고 포커스를 줍니다.
- 필수 입력이 비어 있으면 배경·테두리와 `입력 필요`를 함께 표시합니다. 입력된 값과 선택 항목도 구분합니다. 발주 0EA인 제품의 단가·지급일은 입력을 강제하지 않습니다. 이 안내는 AX 작성 완성도를 보여주며 기존 서버의 검토·상신·승인 권한을 대체하지 않습니다.
- 캠페인 집행 예산·예상 GMV·발주 단가에 1,000단위 쉼표를 입력 중 자동 표시합니다. 상태와 API에는 쉼표 없는 숫자 문자열/숫자를 유지하며 문자·음수·안전한 정수 범위를 벗어나는 금액은 입력하지 않습니다. 수량과 날짜를 금액으로 처리하지 않습니다.
- `공급·비용·현금 계산`을 직접 누르면 계산 완료 후 결과 요약으로 스크롤·포커스가 이동합니다. 예측치 가져오기 중 내부적으로 수행하는 재계산은 작성 위치를 강제로 옮기지 않습니다.
- 결과 요약에서 공급 검산, 조달비와 상단 예산 영역의 반영 위치, 현금과 승인 경로의 위치를 설명합니다. `예산 영역 보기`·`현금 판정 보기`로 각각 이동합니다. 수요·발주량은 가져오기, 일정은 제안일 가져오기를 눌러야 입력에 반영된다는 점과 계산이 승인/발주를 수행하지 않는다는 점을 안내합니다.
- 입력이 달라지면 이전 결과를 숨기고 재계산을 안내합니다. 직접 일정 입력도 `수동`으로 구분해 이전의 산정 채택 상태와 혼동하지 않도록 했습니다.
- 키보드 포커스, aria-required/describedby, 상태 안내와 모션 감소 설정을 지원합니다. 모바일은 단계·결과 카드를 좁은 화면에 맞게 배치합니다.

구현: web/marketing-ux.js, web/marketing-ux.css, web/ax-planning.js, web/campaign.html 및 서버 정적 파일 경로. 기존 원본·시안·보호 폴더와 .gitignore는 변경하지 않았습니다.

검증: 기존 단위 테스트 162건, 실제 브라우저의 빈 필드 안내·다음 입력 이동·연속 금액 입력·쉼표 없는 계산 요청·결과 자동 포커스·반영 위치 링크·입력 변경 시 결과 무효화·모바일. [결과](../../verification/marketing/MARKETING_WRITING_UX_RESULTS.json).

재현: AX 테스트 픽스처가 있는 로컬 서버에서 `W01_WRITING_TEST_BASE_URL=http://127.0.0.1:8089 python3 -m scripts.verify_marketing_writing_ux`. 브라우저에서 값을 수정하지만 저장하지 않으며 계산 API만 호출합니다. Playwright와 Chromium이 필요합니다.

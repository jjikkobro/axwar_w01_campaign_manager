# 캠페인 집행 예산과 마케팅비 산식 · 2026-11-12

## 원본 확인 결과

- A05 §4 및 calculation_definitions.md §1.4: Marketing Spend는 `mkt_ad_spend_ms.ad_cost_krw`의 해당 범위 합계다. 이미 포함된 `influencer_fee_krw`를 다시 더하지 않는다. 제품원가·배송·채널수수료·반품 비용은 별도 손익 항목이다.
- `mkt_ad_spend_ms.csv`: 225행, 25개 캠페인, 인플루언서·퍼포먼스·오프라인 각 75행. 광고비 총 763,913,793원 중 포함 인플루언서비 397,235,169원. 둘을 더하는 방식은 중복이다. 비인플루언서 150행의 fee=NONE은 해당 없음으로 해석하며, 인플루언서 fee 미확인은 임의 0 처리하지 않는다.
- `mkt_budget_plan_ms.csv`: 요청액·예상 GMV·정산/확정일은 있지만 비용 항목별 분해나 공식 미래 예산 산식은 없다. 요청액/예상 GMV는 약 8.89~10.91%, 중앙값 9.60%이지만 이는 부서의 계획 비율이다. 같은 캠페인 과거 광고비/기안 요청액이 약 1.09~6.86배로 다르고 적용 기간도 다르므로 공식 비용 예측식으로 단정하지 않는다.
- 마케팅 거래·광고비·기안은 대표 표본, 재고·자금은 회사 규모다. 따라서 비용 견적·실제 집행 규모를 입증하지 않는 표본 예상비를 회사 현금에 자동 합산하지 않는다.

## 발견한 구현 문제와 변경

기존 UI는 상품 조달 예상비만 계산해 캠페인 집행 예산에 그대로 넣었다. 추가 발주가 없으면 마케팅을 집행해도 예산 0원으로 채워지는 오류가 있었다.

이제 다음 항목을 분리한다.

| 항목 | 사용 |
|---|---|
| 마케팅 집행 예상비 | 매체별 참고 모델. 담당자 채택 시 캠페인 집행 예산에 입력 |
| 상품 조달 예상비 | SKU 발주량×단가의 공통 산식. 별도 SCM 발주·재무 검토 |
| 마케팅비·상품 조달비 참고 합계 | 두 규모/가격 가정의 합산 참고치. 하나의 확정 현금 유출이나 전결 한도를 입증하지 않음 |
| 직접 입력 예산 | 참고 모델과 다를 수 있음. 명시적 0원도 유지 가능. 임의 덮어쓰기 없음 |

원본 기안의 요청액에 상품 조달비가 실제 포함됐다고 단정하지 않는다. 마케팅 집행 예산과 조달 요청을 별도로 검토하는 것이 기존 비용/승인 경계를 유지한다.

## 도출·적용한 참가자 가정

비교 범위는 기준일 이전 종료된 캠페인 중 동일 제품라인·국가·선택 매체이며, 해당하는 경우 플랫폼·포맷·인플루언서도 일치시킨다. 일치 자료가 없으면 다른 집단으로 자동 확대하거나 0원을 채우지 않는다.

비교 캠페인별로:

```
포함 고정비 = Σ influencer_fee_krw
기타 광고비 = Σ ad_cost_krw − 포함 고정비
일별 참고비 = 기타 광고비 ÷ 캠페인 달력일수
```

새 계획에는 매체별로:

```
예상 고정비 = 비교 캠페인의 포함 고정비 중앙값
예상 기간비 = 일별 참고비 중앙값 × 신규 캠페인 달력일수
마케팅 집행 예상비 = Σ 예상 고정비 + Σ 예상 기간비 + 별도 입력 마케팅비
참고 총소요비 = 마케팅비 + 상품 조달비
```

- 광고비에 들어 있는 수수료를 고정/변동으로 분리한 뒤 한 번만 합산한다. 수수료를 광고비에 재가산하지 않는다.
- 인플루언서 비용을 캠페인당 고정비, 나머지 비용을 일수 비례로 두는 것은 참가자 모델 가정이다. 실제 계약의 기간·횟수·성과 보수·최소 집행액을 입증하지 않는다. 비교 관측 수와 원본 행 ID를 표시한다.
- 쿠폰·제작·별도 행사 비용의 미래 견적은 원본만으로 산정할 수 없다. 근거가 없는 매체는 직접 입력/견적 확인을 안내하고, 별도 반영할 마케팅비 입력을 제공한다. 추가 입력 없음이 실제 다른 비용 0원이라는 사실을 뜻하지 않는다.
- 마케팅 참고비 채택 시 모달에서 적용 범위를 명시적으로 확인하고 예산 근거를 저장한다. 서버도 확인과 근거를 요구한다. 실제 승인·집행·지급은 실행하지 않는다.

## 다이나믹 설정과 공통 반영

관리자→계산식 설정에 다음 산식을 등록했다.

- `marketing_fixed_budget`: 마케팅 고정비 예상 · 마케팅 수정.
- `marketing_variable_budget`: 마케팅 기간비 예상 · 마케팅 수정.
- `marketing_execution_budget`: 캠페인 마케팅 집행 예산 · 마케팅/재무 수정.
- `campaign_total_requirement`: 마케팅·상품 조달 참고 합계 · 마케팅/재무 수정.

모두 기존 AST 검증·숫자 범위·정수 원 단위·역할 검증·영향 미리보기·사람 적용·이력과 공통 계산 기준 변경 감지를 사용한다. 영향 미리보기는 마케팅 참고예산의 전후 값을 표시한다. 모델을 바꿔도 과거 담당자가 채택한 예산·승인을 자동 수정하지 않는다. 최신 추천과 저장 기록을 구분한다.

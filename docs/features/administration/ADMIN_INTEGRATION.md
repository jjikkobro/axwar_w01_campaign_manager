# 관리자 통합과 캠페인 홈 분류

## 관리자 메뉴

`/admin#tab=data&role=SCM`에서 기준자료 / 계산식 설정 / AI 프롬프트 설정 / 시스템 기록을 제공합니다. 역할 변경은 시연용이며 개인별 부서 인증은 아닙니다.

- 기준자료는 마케팅(주간 판매), SCM(SKU·재고·발주), 재무(현금·회수·지급·공식 전망)로 묶었습니다. 자료 8종마다 내려받기·업데이트가 있습니다. 공통 `세부 자료 관리` 버튼은 제거했습니다.
- 기존 별도 업무 탭을 제거하고 연체 회수·지급 확인, 별도 계약 검토·통보, 관련 작업 현황을 재무 섹션으로 이동했습니다. 재무 역할에서 연체 회신을 갱신할 수 있습니다. 별도 계약의 승인·통보 실행 기능을 새로 만들지는 않았습니다.
- 계산식 설정은 동일한 관리자 페이지의 패널로 통합했습니다. 기존 `/settings#role=...` 주소는 관리자 계산식 탭으로 이동합니다. 기존 산식 검증·영향 확인·직접 적용·동시 변경 방지·변경 이력은 유지합니다.
- AI 프롬프트 설정은 7단계 초안 작성·저장 준비 화면입니다. 단계 담당 역할만 편집하고 수정자·사유·근거를 저장합니다. 고정 Human-led 원칙을 함께 표시합니다. 기존 AI 호출에는 연결하지 않았고, 변수 치환·실행·적용·자동 상태 변경은 하지 않습니다.

## 자료 업데이트

시스템의 현재 자료를 CSV로 불러와 수정하거나 UTF-8 파이프(|) CSV를 업로드합니다. 출처·자료 구분·수정자·사유·근거를 입력한 뒤 서버 검증 → 변경 행 수 확인 → 직접 저장 순서입니다. 담당 부서 또는 SCM이 수정할 수 있다는 기존 서버 규칙을 유지합니다.

검증 요청은 저장하지 않습니다. 저장 시 자료 버전을 대조하며 잘못된 열·숫자·SKU와 버전 충돌을 거절합니다. 기존 PostgreSQL 사본을 교체하며 원본 파일은 수정하지 않습니다. 자료 변경에 따른 재무 확정 해제·관련 검토 재확인은 기존 정책대로 적용하고, 자료 수정 사건에 수정자·근거도 남깁니다.

## 프롬프트 초안 저장

초안은 기존 w01_events의 `AI 프롬프트 초안 저장` 사건으로 보관하고 최신 초안을 조회합니다. 새 테이블이나 파일 저장을 추가하지 않았습니다. 사건 번호를 낙관적 버전으로 사용해 덮어쓰기 충돌을 차단합니다. 재무 설정·자료 버전·기안·승인 근거를 변경하지 않습니다. 모든 초안은 `runtime_applied=false`이며 적용을 요청하는 API 입력은 거절합니다. 향후 AI 연결·테스트·활성화 절차는 별도 구현 대상입니다.

## 홈

제목을 `내 캠페인`에서 `캠페인`으로 바꿨습니다. 역할별 두 섹션과 마케팅의 새 캠페인 생성 버튼은 유지합니다.

마케팅이 기안을 전달해 ②~⑥에서 다른 담당자가 처리 중이면 과거 마케팅 보완 작업이 남아 있어도 `처리한 캠페인의 현재 위치`에 표시합니다. 버튼은 대기 현황 화면을 엽니다. 이전 작업을 자동 완료·삭제하지는 않습니다.

① 기안 작성, 보류·재검토로 반환된 건, ⑦ 일정 관리 대기 건은 `내가 처리할 캠페인`에 표시합니다. ⑦ 처리 버튼은 오래된 보완 작업이 있어도 일정 관리 화면으로 이동합니다. 종료 기록은 처리한 목록에서 조회하며, 별도 실제 성과 후속 작업이 있는 종료 건은 기존 후속 업무 정책대로 처리 목록에 남을 수 있습니다.

현재 캠페인 3건은 ②~⑥ 또는 승인권자 처리 차례이므로 마케팅 홈에서 처리할 캠페인 0건, 처리한 캠페인 3건입니다. 실제 캠페인을 임의로 ⑦까지 진행시키지 않았습니다.

## 검증

- 단위 테스트 149건.
- 별도 로컬 PostgreSQL DB와 브라우저에서 자료 검증·저장·버전 증가, 잘못된 CSV·역할 차단, 통합 산식 시험 계산, 이전 주소 이동, 프롬프트 초안 저장·미적용·버전 충돌, 마케팅 홈 분류·⑦ 이동 픽스처, 모바일 가로 넘침을 확인했습니다.
- [실행 결과](../../verification/administration/ADMIN_INTEGRATION_RESULTS.json).
- 재현: 캠페인 3건을 복제하고 프롬프트 초안이 없는 별도 테스트 DB/서버에서 `W01_ADMIN_TEST_BASE_URL=http://127.0.0.1:8089 python3 -m scripts.verify_admin_integration`. 이 검증은 시험 자료와 프롬프트를 저장하므로 기존 미리보기 DB를 사용하지 않습니다. Playwright와 Chromium이 필요합니다.

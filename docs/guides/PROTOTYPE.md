## 최우선 Rule · Human-led

현업 담당자가 기존에 하던 업무를 더 쉽게 진행하도록 돕는 것이 최우선입니다. 원본의 업무 흐름·책임·승인권한·데이터 의미를 보존합니다. AI는 출처·계산 기준·가정이 명확한 제안만 하고 담당자가 확정합니다. 원본에 없는 기능은 추가 설계로 표시합니다. [PROJECT_RULES.md](PROJECT_RULES.md)에 2026-11-10 사용자 확정 조건을 기록했습니다.

역할별 화면은 모두 서버에 연결되어 있습니다. 마케팅은 대상 SKU와 실제 회사 규모 순증 가정을 구분해서 작성하고, SCM 인계 전 미입력·과거 범위·별도 근거를 확인합니다. 검토·협의·승인·발주·회신은 담당자의 명시적 기록으로 다음 화면에 반영됩니다. 화면을 열거나 AI 초안을 생성한 것만으로 승인하지 않습니다.

## 구현 범위

마케팅·SCM·재무·승인권자가 역할을 전환합니다. SCM은 전체 도구를 관리합니다. 마케팅은 주간 판매, 재무는 현금·회수·지급·공식 전망, SCM은 SKU·재고·발주를 업로드·수정합니다. 모든 역할이 근거 파일과 회신을 등록할 수 있습니다. 대회 운영 배포는 로그인 없이 접속하며 역할 전환은 시연용으로 실제 개인별 부서 권한 인증이 아닙니다. 담당자 입력은 접속 프로필에서 자동으로 채웁니다. 현재 개인 인증 미연결 상태의 기본값은 역할별 `담당자 (시연)`이며, 공유 시연의 표시 이름은 `PROTOTYPE_USER_NAME`으로 지정할 수 있습니다. 자동 입력은 수정 가능하며 기존 작성자·과거 이력과 구분합니다.

PostgreSQL에 자료 버전·검토 건·첨부·재무 결정·작업·사건 이력을 저장합니다. SQLite/브라우저 저장 대체 경로는 없습니다. 원본 04_원본데이터와 .claude/.codex/.agents/.gitignore는 변경하지 않습니다.

## 실행

Python 3.14, PostgreSQL과 requirements.txt의 드라이버가 필요합니다.

```sh
pip install -r requirements.txt
export DATABASE_URL='postgresql://사용자:비밀번호@호스트:5432/데이터베이스'
python -m scripts.migrate
python -m scripts.seed
python -m app.server
```

기본 주소: http://127.0.0.1:8080

로컬 기본 실행은 로컬 주소에만 바인딩합니다. 대회 운영 배포는 PUBLIC_ACCESS=true로 모든 주소에서 로그인 없이 접속합니다. Docker는 AI_SETTINGS_BACKEND=environment를 사용하며 AI_API_KEY·AI_MODEL·SESSION_SECRET은 AXhub 런타임 환경변수로 등록합니다. DATABASE_URL은 AXhub가 주입합니다. 비밀값은 소스에 넣지 않습니다.

마이그레이션은 기존 테이블·자료를 삭제하지 않고 w01_finance, w01_tasks 등을 추가합니다. seed는 기존 수정 자료를 덮어쓰지 않고 없는 자료만 추가합니다. 운영 반영 전에 DB 백업과 역할별 실제 인증을 준비해야 합니다.

## 약정 분류와 승인 경로

재무 담당자가 유출일·금액·신규 여부·연결 발주·결정자·사유·근거·의견·대안을 입력합니다. 요청자가 재무 결정·승인·결재선을 입력 데이터에 끼워 넣어 우회할 수 없도록 서버가 입력 필드를 제한합니다.

| 유형 | 평시 경로 |
|---|---|
| 재고 발주 | SCM 전결 |
| 캠페인 집행 | 건별 1천만원 이하 마케팅. 초과 또는 소속 기안 총액 1억원 초과는 Masil 대표 + 그룹 보고 |
| 연간 전속계약 | 10억원 이하 Masil 대표, 초과 CEO/이사회 |
| 하회구간 신규 약정 | 위 경로에 우선하는 CEO/이사회 |

기존 SPO-0001~0014는 하회 원인이며 신규로 재라우팅하지 않습니다. 증량·추가발주·지급일 앞당김의 증가/조기 유출분을 신규 약정으로 해석합니다. 감량·연기·취소는 평시 SCM 변경 검토입니다. 기존 약정이라고 분류하려면 원본 지급액·날짜·연결 발주가 일치해야 합니다. 이미 전달된 발주의 변경은 새 검토 건으로 요청합니다.

지급일 누락 또는 전망 범위 밖은 판정 불가로 차단하고 확인 작업을 생성합니다. 신규 여부가 미확인이면 보수적으로 검토하며 승인하지 않습니다. 재무 확정 전 CEO 합집합 구간에 걸리면 'CEO 상신 대상(재무 확정 대기)'입니다. 미응답으로 평시 경로로 낮추지 않습니다.

화면의 '결재 판정'은 계산된 경로이고 '업무 상태'는 접수·회신·승인·발주 진행 단계입니다. 결재선 산출이나 재무 확정은 승인 행위가 아닙니다. 최종 승인권자 역할의 명시적 행동과 조건 기록이 필요합니다. 조건부 승인은 발주를 허용하지 않으며 조건 확인 후 재상신·사람 재승인이 필요합니다. 반려·보류는 후속 작업으로 연결합니다.

캠페인/연간계약 경로 계산은 구현했지만, 선택 사항인 기안 25건 일괄 분석·날짜 역전·3영업일 상신기준일 기능은 구현하지 않았습니다. 캠페인 집행 경로 검토 시 소속 기안 ID·총액·묶음 근거를 직접 입력하며 표본 금액을 전사 현금에 합산하지 않습니다.

## AI와 시스템 초안

상신 패킷에는 최우선 Rule·출처 파일·자료 버전·계산 주차·가정을 포함합니다. AI 출력은 미검증 초안이며 사람의 판단을 대체하지 않습니다. 상신 패킷에는 영향 SKU·재고커버·하회구간·결재선·적용 조항·재무 의견·대안·모의 회신이 포함됩니다. 초안은 생성 시점의 검토·재무·자료 버전을 보관합니다. 생성만으로 상태·승인·지급을 변경하지 않습니다. 오래된 초안은 새로운 근거로 재생성하고 사람이 검토해야 합니다.

관리자 → AI 프롬프트 설정에서 OpenAI API 키·모델·연결 사용 여부를 저장합니다. 기본 모델은 gpt-5-mini이며 사용 가능한 모델로 수정할 수 있습니다. 키를 입력한 뒤 연결 사용을 선택하고 저장하세요. 빈 키는 기존 키를 유지하며 삭제 버튼으로 제거할 수 있습니다. 저장 자체는 API를 호출하지 않으며 연결 테스트·검토 초안 생성 버튼을 누르면 호출합니다.

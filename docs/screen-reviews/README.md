# W01 화면 검토·적용 현황

현재 서비스 진입 화면: [역할별 두 캠페인 목록·관리자 분리(0.7)](../features/workflow/ROLE_HOME.md). 상세 캠페인 화면의 원본 플로우는 유지합니다.

최신 기능: [0.6 W01 최종 Goal 업그레이드](../features/workflow/W01_UPGRADE.md). 원본 13개 화면·단계 플로우를 유지하고 공유 SKU 계획·수요 검증·공식/재전망 비교·협의·후속 의무·담당 큐·체류시간을 `/hub`에 연결했습니다. 103개 테스트와 실제 DB/브라우저/재시작 증거를 확인하세요. 로컬 확인은 http://127.0.0.1:8088/ 입니다.

최신 UI 기준: 사용자의 “첨부한 시안과 완벽하게 동일하게” 지시에 따라 원본 마크업·스타일·로직을 직접 사용합니다. [원본 구현·26개 캡처 비교·업무 검증](14-original-design.md)을 확인하세요. 이전 13개 마이그레이션의 화면 재구성은 기본 화면에서 교체됐으며 서버 동작과 상세 관리 기능은 보존했습니다.

현재 기준은 사용자가 전체 마이그레이션을 지시한 `W01_screens`입니다. 2026-11-10에 13개 화면을 동일 서버 데이터와 역할별 흐름으로 연결했습니다. 이번 13개 적용에 이전 단계별 컨펌 대기를 다시 요구하지 않습니다. 후속 업무 정책 변경 제안은 기존 Human-led·근거 확인 규칙을 따릅니다.
